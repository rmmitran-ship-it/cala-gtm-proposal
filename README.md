# Cala GTM Proposal

An interactive, single-page GTM proposal for Cala.ai — covering market diagnosis, segment prioritisation, and a two-track (direct + partner) growth motion for the next 90 days. Built as a self-contained HTML/CSS/JS site styled after Cala's own brand, for founders and GTM stakeholders reviewing the proposal.

Live: `https://rmmitran-ship-it.github.io/cala-gtm-proposal`
